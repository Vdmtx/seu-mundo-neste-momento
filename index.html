SOBRE ESTE MONITOR

Tempo quase real, não ficção.

“Ao vivo” significa a leitura mais recente publicada por cada fonte. Terremotos, clima espacial, eventos naturais, temperatura, notícias e posição orbital têm ritmos diferentes. O painel mostra horário, origem e estado de cada fonte; quando algo falha, informa a falha em vez de inventar dados.

O GitHub Pages é estático. As leituras são feitas diretamente de APIs públicas e usam o último arquivo consolidado pelo GitHub Actions como contingência.
